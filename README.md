# PulseForge AI — YouTube & Facebook Content Automation OS

Complete end-to-end autonomous content operations engine for YouTube and Facebook creators and media networks.

## Features
- **Trend Intelligence & Radar**: Continuous scanning and audience fit scoring.
- **7-Factor Idea Scoring Matrix**: Algorithmic ranking and Kanban stage management.
- **Research & Gate B Fact-Checking**: Source verification and claim confidence tracking.
- **Multi-Format Script Studio**: Structured beat scripting for YouTube Explainer, Shorts, and Facebook companion posts.
- **Production QC & Asset Ledger**: 8-point quality verification, TTS voiceover generation, and thumbnail ranking.
- **Multi-Channel Publishing**: Safe authorization, scheduling, and distribution queue.
- **Diagnostics & A/B Experimentation**: 6-signal retention diagnostics and split-testing optimization.
- **Community Agent**: AI sentiment triage and human escalation routing.
- **Security & Governance**: Human approval gates and global emergency kill switch.

## Getting Started

### Prerequisites
- Node.js 18+ (Node.js 20+ recommended)
- npm or yarn

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env.local`:
   ```bash
   GEMINI_API_KEY="your-api-key-here"
   APP_URL="http://localhost:3000"
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
